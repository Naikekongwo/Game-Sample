# Eclipsea 移植分析报告

> 本报告分析新版 OpenCore 引擎相对旧版的改动、`Game-Project` 与 `Aozora-Re`
> 的项目结构差异，以及 `Game-Sample` → `Eclipsea` 的移植方案与实现记录。

---

## 一、OpenCore 引擎改动分析

### 1.1 版本与基础栈

| 维度 | 旧版（Game-Sample 内嵌） | 新版（Aozora-Re 子模块） |
| ---- | ------------------------ | ------------------------ |
| 引擎版本 | 25.11（`ENGINE_VERSION_MAJOR/MINOR`） | 26.1 |
| 媒体库 | SDL2 / SDL2_mixer / SDL2_ttf / SDL2_image | SDL3 / SDL3_image / SDL3_ttf |
| C++ 标准 | C++26（实验性 import std） | C++23 |
| 代码组织 | 直接内嵌在项目 `src/OpenCoreSrc` + `include/OpenCore` | 独立 git 子模块 `modules/OpenCore`（含 rapidjson 嵌套子模块） |

### 1.2 头文件结构差异（新增 / 删除 / 改动）

**删除的头文件（旧有而新无）：**

- `Asset/ResourceManager.hpp`、`Asset/MapLoader.hpp`、`Asset/SoundLoader.hpp` → 被 **`Asset/PackageManager.hpp`** 取代
- `Runtime/Audio/SoundEffectManager.hpp`（音频模块整体移除）
- `Runtime/Config/SettingsManager.hpp`（设置管理器移除）
- `Runtime/Gameplay/**`（实体/背包/物品/物理/世界控制器整体移除）
- `Runtime/Graphics/Sprite/**`（Mob/Tile/Waterrect/HealthBar/ItemSprite/Entity.h 移除）
- `Runtime/Graphics/UI/ItemContainer.hpp`、`MapExplorer.hpp`、`MultiImageBoard.hpp`（玩法 UI 移除）
- `Runtime/Graphics/Manager/TextureMeta.hpp`（数字 ID 版纹理元数据移除）
- `World/Map/**`（地图系统整体移除）

**新增的头文件：**

- `Asset/PackageManager.hpp`（资源包管理器）
- `Core/Info/GameInfo.hpp`、`Core/Info/GraphicsInfo.hpp`、`Core/Info/ResourceInfo.hpp`（信息注册结构体）
- `Runtime/Graphics/UI/ToolMenu.hpp`
- `World/Helpers/SequentialPipeline.hpp`（顺序任务管道）

### 1.3 关键 API 改动

#### 资源管理：数字 ID → 资源名

旧版通过 `ResManager.LoadResourcesFromJson(id)` + `ResManager.GetTexture(texID)`，
以**数字 ID + JSON 清单**方式加载资源；新版改为：

```cpp
Package->registerResources({
    {RscTexture, "menu_daytime", "assets/backgrounds/menu_daytime.png"},
    {RscFont,    "OpenCoreFont", "assets/ui/font/OpenCoreFont.ttf"},
});
auto tex = Package->getTextureObject({"menu_daytime", 1, 1});
```

UI 工厂模板 `UI<T>` 的纹理参数从 `short texID` 改为 `string_view textureName`。

#### GameInfo 构造

旧版（位置参数构造，含 `TargetResolutionWidth/Height`、`nearestScaling`）：

```cpp
std::make_unique<GameInfo>("Eclipsea", 1, 8, true,
    std::make_unique<PreloadStage>(timer, sController), 1920, 1080, true);
```

新版（默认构造 + 字段赋值，分辨率/缩放拆到 `GraphicsInfo`）：

```cpp
auto info = std::make_unique<GameInfo>();
info->gameName = "Eclipsea";
info->entranceStage = std::make_unique<PreloadStage>();
info->_graphicsInfo.resolutionWidth  = 1920;
info->_graphicsInfo.resolutionHeight = 1080;
```

#### 场景（Stage）生命周期

- 旧版：构造时显式传入 `(Timer*, StageManager*)`，且必须实现
  `handlEvents(SDL_Event*)`（纯虚）。
- 新版：**默认构造**，`StageManager::configure()` 在加入舞台后自动注入
  `timer` / `sController`；`handlEvents(SDL_Event*)` 已删除，仅保留
  `parseEvents(Event*)`（`Event` 封装 `SDL_Event`，提供 `GetSDLEvent()`）。
- `Stage` 基类内置 `SequentialPipeline pipeline` 成员，供顺序动画/流程使用。

#### 引擎单例暴露面

- 删除：`OpenEngine::Run()`、`getEntityRegister()`、`getServerWorldController()`。
- 新增：`getPackageManager()`。
- `OpenCoreManagers` 命名空间缩减为 `ThrManager / EvtManager / GFXManager`，
  删除 `ResManager / SFXManager / SetManager / TexMetaManager`。
- `Gameplay::EntityReg / ItemMgr` 命名空间变量整体移除。

#### 其他

- SDL3 事件/枚举重命名：`SDL_MOUSEBUTTONDOWN → SDL_EVENT_MOUSE_BUTTON_DOWN`、
  `event.key.keysym.sym → event.key.key`、`SDLK_w → SDLK_W`、
  `SDL_RenderSetClipRect → SDL_SetRenderClipRect`、
  `SDL_GameController* → SDL_Gamepad*` 等。
- `DEBUG_MAP` 调试标志被 `DEBUG_MAIN` 等取代。
- 动画 API 基本兼容（`Animate().Timer/Move/MoveR/Fade/Scale/Frame/SubStart/SubEnd/Commit`），
  其中 `Move` 参数为 `uint16_t`（旧代码中负坐标会产生回绕）。

## 二、Game-Project 与 Aozora-Re 项目结构差异

| 维度 | Game-Project（旧，Game-Sample） | Aozora-Re（新） |
| ---- | ------------------------------ | --------------- |
| 项目名 | Eclipsea（游戏名） | Aozora（青空下的约定） |
| 目录布局 | `src/OpenCoreSrc` + `src/ProjectSrc`、`include/OpenCore` + `include/Eclipsea` | `src/` + `src/Stage`、`include/Aozora`、`modules/OpenCore`（子模块） |
| 引擎接入 | 内嵌（源码直接参与编译） | git submodule + `add_subdirectory(modules/OpenCore)` |
| 入口 | `project/Game-Sample.cpp` | `project/Aozora.cpp` |
| 启动类 | `Eclipsea::StartUp()`（`src/ProjectSrc/Eclipsea.cpp`） | `Aozora::StartUp()`（`src/Aozora.cpp`） |
| CMake | SDL2 直接链接、C++26 | C++23、`target_link_libraries(... OpenCore SDL3*)` |
| 资源 | `assets/assets/...`（双层）+ JSON 清单 `STAGE_10001.json` | `assets/assets/...` 单层 `assets/<分类>/...`，`PackageManager` 注册 |
| 代码量 | 项目源码约 7562 行 | 项目源码约 465 行（大量玩法已移除） |
| 场景 | Preload/Main/Pause/Story/Gameplay/DualGameplay/Purifier/Container/WorldEditor | 仅 Preload/Main |

**差异本质：** Aozora-Re 是"纯 UI + 引擎演示"型项目，玩法层（实体/物品/地图/
世界控制器/音频）在新引擎中已移除；而 Game-Project 正是重度依赖这些被移除
系统的玩法游戏。

## 三、移植方案（Game-Sample → Eclipsea）

### 3.1 总体策略

用户确认三项决策：

1. **玩法系统 → 项目级重新实现**（不修改引擎源码）
2. **引擎接入 → git submodule 引用**
3. **音频 → 项目级 SDL3_mixer 模块**

### 3.2 新项目目录结构

```
Eclipsea/
├── CMakeLists.txt                  # C++23 / SDL3 / OpenCore 子模块 / SDL3_mixer
├── .gitmodules                     # OpenCore 子模块
├── modules/OpenCore                # git submodule（26.1 版本，与 Aozora-Re 对齐）
├── include/Eclipsea/
│   ├── Eclipsea.hpp                # 资源 ID 宏 + 场景引用 + EclipseaApp
│   ├── Core/                       # 项目级核心
│   │   ├── GameSettings.hpp/.cpp   # 替代旧 SettingsManager（含净水器状态）
│   │   ├── AudioManager.hpp/.cpp   # SDL3_mixer 音频（替代 SoundEffectManager）
│   │   └── EclipseaTextures.hpp/.cpp # 数字ID→资源名桥接 + MakeTexture
│   ├── Gameplay/                   # 项目级玩法（自旧 OpenCore 移植）
│   │   ├── Gameplay.hpp            # Gameplay 命名空间别名 + getServerWorldController()
│   │   ├── Backpack/ Entity/ Physics/ WorldController/ Map/ Sprite/ UI/ TextureMeta.hpp
│   └── Stage/                      # 全部场景
├── src/
│   ├── Eclipsea.cpp                # StartUp：注册资源/实体/物品/世界 + 主循环
│   ├── Core/                       # GameSettings / AudioManager / EclipseaTextures
│   ├── Gameplay/                   # 玩法实现（移植自旧引擎，适配新 API）
│   └── Stage/                      # 场景实现（重写适配新生命周期）
├── project/Eclipsea.cpp            # main()
├── resources/                      # 图标 / PSP 图标
└── assets/                         # 游戏资源（单层 assets/<分类>/...）
```

### 3.3 关键移植点

| 旧用法 | 新实现 |
| ------ | ------ |
| `OpenCoreManagers::ResManager.GetTexture(id)` | `EclipseaTextures::getInstance().getTexture(id)` |
| `MakeTexture(x, y, texId)` | 项目级自由函数（内部走 PackageManager） |
| `OpenCoreManagers::SFXManager.*` | `Eclipsea::AudioManager::getInstance().*`（SDL3_mixer） |
| `OpenCoreManagers::SetManager.*` | `Eclipsea::GameSettings::getInstance().*` |
| `OpenCoreManagers::TexMetaManager` | `EclipseaTextureMetaManager`（重命名防冲突） |
| `Gameplay::EntityReg / ItemMgr` | 项目级 `Gameplay` 命名空间（= `EclipseaGameplay`） |
| `OpenEngine::getServerWorldController()` | `getServerWorldController()`（WorldController 单例） |
| `UI<T>(id, layer, texID, fx, fy)` | `UI<T>(id, layer, "texName", fx, fy)` |
| 场景构造 `(Timer*, StageManager*)` | 默认构造，`configure()` 自动注入 |
| `handlEvents(SDL_Event*)` | `parseEvents(Event*)` |
| SDL2 API | SDL3 API（事件/枚举/渲染重命名） |

### 3.4 命名冲突处理

- `TextureMeta`（数字 ID 版，玩法模块）与新版引擎 `TextureMeta`（资源名版）
  同名 → 玩法模块重命名为 **`EclipseaTextureMeta`**。
- 项目命名空间 `Eclipsea` 与游戏入口类 `Eclipsea` 冲突 → 入口类改名
  **`EclipseaApp`**。

### 3.5 编码注意（踩坑记录）

- 旧源码为 UTF-8；PowerShell 5.1 的 `Set-Content` 默认以非 UTF-8 写出会损坏
  中文字符串字面量（丢失 `"` 字节导致"unterminated string"编译错误）。
- 修复：所有批量改写统一使用 `[System.IO.File]::ReadAllText/WriteAllText`
  （UTF-8 无 BOM）。

## 四、构建与运行

```bash
# 首次克隆子模块
git submodule update --init --recursive

# 配置（与 Aozora-Re 一致的 MinGW/Clang 工具链）
cmake -S . -B build -G "MinGW Makefiles" -DCMAKE_BUILD_TYPE=Debug

# 构建（自动拷贝 assets 到输出目录）
cmake --build build
```

产物：`build/Eclipsea.exe`（已成功编译链接、通过启动冒烟测试）。

## 五、交互接线记录（已完成）

- `MapExplorer` / `ItemContainer` 已由旧 `handlEvents(SDL_Event&)` 迁移为
  新版 `parseEvents(Event*, float totalTime)` 重写：
  - 两者均先调用 `UIElement::parseEvents`（处理 `WINDOW_RESIZED` 纹理脏污标记），
    再经 `event->GetSDLEvent()` 取回 `SDL_Event&` 执行原有逻辑。
  - `MapExplorer` 通过 `Elements` 管理器自动接收事件派发，并把事件转发给子级
    `m_itemContainer`；`PurifierStage` 中的 `ItemContainer` 也经由
    `Elements->parseEvents` 自动派发。
  - 恢复的交互：W/A/S/D 与方向键移动视角、手柄十字键移动、背包点击/悬空槽
    放置/取出物品、点击中央喝水恢复生命、Enter 与附近实体交互（进入净化器）。
- 音频模块为项目级 SDL3_mixer 基础实现（单 BGM 轨道 + 每音效一轨道），
  音量语义与旧引擎 0~128 保持一致。
- `Move` 动画参数为 `uint16_t`，旧代码中的负坐标（如 StoryStage 文字滚动）
  存在回绕，属于旧项目原有行为，未做改动。
- 世界编辑器（`ECLIPSEA_DEBUG_WORLD`）默认关闭，可在 `Eclipsea.hpp` 打开。
